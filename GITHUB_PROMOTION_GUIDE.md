## 3. 📦 Оформление первого Релиза (GitHub Releases)

Пользователи GitHub значительно активнее ставят звезды проектам, которые можно сразу скачать и запустить без долгой сборки через консоль.

### Как опубликовать релиз:
1. Перейдите во вкладку **Releases** -> **Draft a new release**.
2. В поле **Choose a tag** напишите `v1.0.0` и выберите **Create new tag on publish**.
3. В поле **Release title**: `v1.0.0 — Public Release (Windows & Android APK)`
4. В поле описания вставьте:
   ```markdown
   ## 🎬 TT Video Automator v1.0.0

   ### 🌟 What's Included:
   - **Windows Standalone App** (`tt_video_automator_win64.zip`): Full desktop version with parallel FFmpeg batch engine, Whisper AI karaoke subtitles, and visual drag-and-drop overlay editor.
   - **Android Release APK** (`tt_video_automator.apk`): High-speed hardware GPU engine (100–200 FPS via OpenGL ES 3.0 & MediaCodec).

   ### 🚀 Features:
   - AI Smart Cut on episodes via DeepSeek & Gemini
   - Automated video unique-fication (speed, color grading, noise, EXIF spoofing under iPhone 14 Pro)
   - Offline Whisper AI transcription & viral post copywriting
   - Dynamic blur background and split-screen gameplay overlays
   ```
5. Прикрепите скомпилированные файлы:
   - Скомпилированный Windows-билд: упакуйте папку `build\windows\x64\runner\Release` в `tt_video_automator_win64.zip`.
   - Скомпилированный Android APK: `build\app\outputs\flutter-apk\app-release.apk` (переименуйте в `tt_video_automator_v1.0.0.apk`).
6. Нажмите **Publish release**.
