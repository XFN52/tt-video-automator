# TT Video Automator 🚀

Кроссплатформенное приложение на **Flutter (Android & Windows Desktop)** для автоматизированной пакетной нарезки, уникализации, форматирования длинных видео в вертикальный формат **9:16** (TikTok, YouTube Shorts, Instagram Reels, VK Клипы), генерации караоке-субтитров через **Whisper AI**, создания вирусных хуков/постов через **LLM (DeepSeek / Gemini)** и сверхбыстрого аппаратного рендеринга (100–200 FPS на мобильном GPU).

---

## 🔥 Ключевые возможности

### 1. 🤖 ИИ Авто-Нарезка на Серии (AI Smart Cut & Cliffhanger Engine)
* **Интеллектуальный анализ транскрипта**: Whisper AI транскрибирует речь с пословными таймкодами, а LLM (DeepSeek V3 / Gemini 3.7 Flash) анализирует смысловые блоки и автоматически разбивает видео на логичные вирусные серии (30–45с, 45–60с, 60–90с или авто-клиффхэнгер).
* **Генерация клиффхэнгеров**: ИИ завершает каждую часть на самом интригующем моменте для максимального удержания аудитории.
* **Авто-генерация хуков и постов**: Для каждой серии автоматически создается цепляющий заголовок-хук, текст публикации с призывом к действию (CTA) и пакет вирусных хэштегов, сохраняемых в `*_post.txt` и `*_meta.json`.

### 2. ⚡️ Аппаратный Zero-Copy GPU Движок (Android MediaCodec + OpenGL ES 3.0)
* **Сверхвысокая скорость (100–200 FPS)**: На Android обработка выполняется без использования медленных мобильных сборок FFmpeg — напрямую через системные кодеки `MediaCodec` и шейдеры `OpenGL ES 3.0`.
* **Zero-Copy Pipeline**: Аппаратный декодер отправляет кадры напрямую в `SurfaceTexture` текстуру OpenGL (`GL_TEXTURE_EXTERNAL_OES`), шейдеры в реальном времени накладывают фоновое размытие (Box Blur), видео-плашки, цветовую коррекцию, динамический шум и караоке-текст, после чего кадр передается напрямую в энкодер без копирования в оперативную память.
* **Плавный и честный прогресс**: Монотонный расчет прогресса с аппаратным троттлингом (50 мс) и асинхронным сбросом на диск исключает лаги интерфейса.

### 3. 🎤 Локальный Whisper AI и Караоке-Субтитры
* **Пословная синхронизация речи**: Извлечение аудиодорожки (16 kHz Mono WAV) и генерация точных пословных таймкодов через движок `whisper.cpp` (модели GGML Tiny / Base) на Android и Windows (cuBLAS CUDA + AVX2).
* **Мгновенное переиспользование (0s Whisper Cache)**: Распознанные токены кэшируются в оперативной памяти и на диске (`whisper_cache/`), поэтому повторная нарезка того же видео или его частей происходит мгновенно без повторного прогона нейросети.
* **Стиль караоке в духе TikTok**: Динамическая подсветка текущего произносимого слова желтым/голубым цветом, черная контрастная обводка и настраиваемое вертикальное положение.

### 4. 🎨 Форматирование в 9:16 и Глубокая Уникализация
* **Режимы компоновки кадра**:
  * *Размытый фон (Blur)*: центрирование исходного видео с динамическим размытым фоном под соотношение 9:16 (1080x1920).
  * *Сплит-скрин (Split-Screen)*: исходное видео в верхней половине, в нижней — цикличное геймплей-видео (GTA V, Minecraft, Subway Surfers).
* **Алгоритмы обхода теневых спам-фильтров**:
  * Микро-изменение скорости видео и аудио (1.00x – 1.08x).
  * Цветокоррекция с рандомизацией гаммы, контраста, насыщенности и яркости.
  * Наложение легкого цифрового шума и горизонтальное зеркалирование.
  * Спуфинг EXIF-метаданных (Apple iPhone 14 Pro / QuickTime).

### 5. 🎯 Интерактивный Визуальный Редактор Пресетов (FullPreviewEditor)
* **Живой холст 9:16**: Наглядное Drag-and-Drop позиционирование и масштабирование плашки с хуком, бейджа серии («Часть 1»), караоке-субтитров и анимированных видео-баннеров.
* **Прямая работа с файлами (Zero-Cache File System)**: Благодаря `StoragePathHelper` и разрешению `MANAGE_EXTERNAL_STORAGE`, приложение работает напрямую с физическими файлами накопителя (`/storage/emulated/0/...`), полностью минуя временный кэш Android, который может удаляться системой.

### 6. 🤖 Готовность к Интеграции с Автопостером (Autoposter Bridge)
* Приложение формирует полный пакет публикации (`*.mp4` + `*_post.txt` + `*_meta.json`) и готово к автоматической отправке на удаленный сервер автопостинга на базе **Camoufox + Xray-core** (подробности в [AUTOPOSTER_API_SPEC.md](AUTOPOSTER_API_SPEC.md)).

## 🏛 Архитектура Проекта

```
lib/
├── core/
│   ├── database/             # Isar NoSQL хранилище очереди задач и пресетов
│   ├── ffmpeg/               # Построитель сложных filtergraph для FFmpeg (Windows)
│   ├── router/               # Навигация GoRouter
│   ├── services/             # Хранилище настроек (AppSettingsService)
│   ├── theme/                # Темная тема (TikTok Dark / Neon Pink)
│   └── utils/                # StoragePathHelper, FileUtils, FontExtractor
│
├── features/
│   ├── ai_assistant/         # Интеграция DeepSeek / Gemini, диалог ИИ Авто-Нарезки
│   ├── dashboard/            # Главный экран очереди задач, запуск пакетной обработки
│   ├── presets/              # Модели пресетов, визуальный 9:16 Canvas редактор
│   ├── processing/           # BatchQueueManager, NativeGpuEngine, FFmpegEngine
│   ├── subtitles/            # WhisperService, пословные токены, генератор ASS караоке
│   ├── tasks/                # StateNotifier очереди Riverpod, модели VideoTask
│   └── trimmer/              # Визуальный таймлайн-триммер по ключевым кадрам
│
android/app/src/main/kotlin/.../gpu/
├── AudioTrackMuxer.kt        # Потоковый мультиплексор аудиодорожек без пережатия
├── EglCore.kt                # Инициализация EGL контекста и аппаратных Surface
├── GlProgram.kt              # Компилятор шейдеров OpenGL ES 3.0
├── GpuVideoRenderer.kt       # Шейдерный рендерер (Blur, караоке, баннеры, хуки)
└── GpuVideoTranscoder.kt     # Zero-Copy MediaCodec транскодер (100-200 FPS)
```

## 🛠 Стек Технологий

* **Фреймворк**: Flutter 3.38+ (Dart 3.x).
* **Платформы**: Android (API 26+) & Windows 10/11 (x64).
* **Стейт-менеджмент**: Flutter Riverpod 2.x.
* **Локальная БД**: Isar Database 3.1 NoSQL.
* **Аппаратный рендер (Android)**: Kotlin, Android NDK, MediaCodec, OpenGL ES 3.0, EGL 1.4.
* **Десктоп рендер (Windows)**: FFmpeg 6.0 CLI + Nvidia NVENC (`h264_nvenc`).
* **Нейросети**:
  * Речь: `whisper.cpp` (GGML Tiny/Base).
  * Текст и нарезка: DeepSeek V3 / Gemini 3.7 Flash API.
* **Медиаплеер**: `video_player` + `fvp` (MDK DirectX/Vulkan бэкенд).

## 🚀 Установка и Сборка

### 1. Клонирование репозитория
```bash
git clone https://github.com/XFN52/tt-video-automator.git
cd tt-video-automator
```

### 2. Установка зависимостей
```bash
flutter pub get
```

### 3. Генерация моделей базы данных Isar
```bash
dart run build_runner build --delete-conflicting-outputs
```

### 4. Запуск на Android устройстве (через ADB)
```bash
flutter run -d <device_id>
```

### 5. Сборка релиза для Android (APK)
```bash
flutter build apk --release
```
Готовый APK: `build/app/outputs/flutter-apk/app-release.apk`

### 6. Запуск и сборка на Windows
```bash
flutter run -d windows
flutter build windows --release
```
Готовый EXE: `build/windows/x64/runner/Release/tt_video_automator.exe`
